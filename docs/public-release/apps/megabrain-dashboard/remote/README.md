# Acesso remoto opcional

A central local funciona sem túnel. Esta distribuição não inclui URL pública,
token, credencial ou infraestrutura de outra pessoa.

`run_tunnel.py` só executa um túnel dedicado já configurado e verificado.
`wrangler.jsonc.example` é um exemplo para o operador revisar. Login, criação,
publicação e ativação não fazem parte de `INSTALAR-MEGABRAIN.cmd`.

O botão **Levar no celular** informa o estado real da sua conexão. Fora da rede,
o computador precisa estar ligado e o acesso HTTPS autenticado configurado.
Uma tela responsiva não comprova conexão remota ativa.
