# 260914_narrado — modelo de relatório narrado

**O que é:** deck HTML autocontido (PowerPoint comentado) com narração TTS,
legenda sincronizada, modo guiado, 3 temas de cor e animações de entrada.
Nasceu da entrega aprovada `Portfolio/00_PARA-VOCE/260914_RELACAO-GERAL-APRESENTACAO/`
e da revisão Fable médio de 14/09 (bugs T1–T3 já corrigidos NESTE modelo).

**Arquivos:**
- `MODELO-relatorio-narrado.html` — copie e preencha os blocos `═══ EDITE`.
- Skill de uso: `motor/skills/relatorio-narrado/SKILL.md` (passos, regras, lições).

**Mínimo para funcionar:**
1. HTML + `narr_NN.mp3` na MESMA pasta (TTS pt-BR, texto idêntico ao array `NARR`).
2. Entregar a pasta inteira em `00_PARA-VOCE/` do projeto, com LEIA-PRIMEIRO.
3. Conferir nomes de classe únicos antes de fechar (lição T1).
