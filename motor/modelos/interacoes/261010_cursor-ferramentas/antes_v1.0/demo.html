Ferramentas do cursor

Segure o clique por 2 segundos em qualquer ponto, sem arrastar. Um menu abre em leque em volta do ponteiro. Escolha Comentar e clique onde quiser deixar uma nota. Esc volta ao clique normal.

    2

    Cole na página

    Dentro de uma tag script, antes de fechar o body. Em artefato do claude.ai, cole inline.

    3

    Ligue com uma linha

    Chame o iniciar. As opções abaixo ajustam tempo, ferramentas e onde a nota fica.

    var cf = CursorFerramentas.iniciar({
  segurarMs: 2000,          // tempo segurando
  modo: 'auto',             // claude.ai quando houver; senão nota local
  chave: 'notas-meu-relatorio',
  aoMudarNotas: function (notas) { console.log(notas); }
});
cf.notas();                 // [{ n, texto, onde, criado_em }]
    OpçãoPadrãoPara que serve
    segurarMs2000Quanto tempo segurar para abrir o menu.
    tolerancia10 pxQuanto o mouse pode mexer sem cancelar.
    modoautoauto: no claude.ai abre o comentário nativo; fora dele, nota local. local: sempre nota na página.
    chiptrueBotão fixo no canto com a ferramenta atual. Aceita um elemento para morar dentro dele, ou false.
    ferramentasInteragir, ComentarLista de ferramentas: id, nome, ícone, classe de cursor e o que fazer no clique.
    chaveendereço da páginaOnde as notas locais ficam salvas no navegador.
    ignorarcampos de textoOnde segurar não abre o menu (para não atrapalhar quem seleciona texto).
    aoMudar, aoMudarNotas, aoEventonenhumAvisos para a página reagir: troca de ferramenta, notas, menu aberto.
