# dna/

`RELATORIO-DNA.html` — relatório DNA do megabrain (protocolo, genérico). `dna.json` — os mesmos dados em JSON puro. `.dna-backup/` — versões anteriores.

Gerado por `bin/mb-relatorio-dna.py` — nunca editar os arquivos desta pasta na mão; edite a fonte (`MEGABRAIN.md`, `SKILL.md`) e rode o script de novo.

Procurando o relatório de UM projeto (não o protocolo)? É outro artefato: `RELATORIO.html` na raiz do projeto, gerado por `bin/mb-relatorio-projeto.py`.
