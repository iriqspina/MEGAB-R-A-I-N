Catálogo visual do megabrain

8 mecânicas prontas. Regra: antes de inventar um visual, procure aqui. Escolher um id e preencher os dados custa ~10× menos token do que escrever HTML e CSS do zero — e o resultado já sai no tema do sistema, com contraste conferido e responsivo.

barra-segmentos · fluxo-etapas · kpi-linha · mapa-camadas · matriz · semaforo · timeline · trilha-dupla
barra-segmentos Barra de segmentos

quando: uma população repartida — 16 projetos por versão, tokens por fase, tarefas por estado

dados: titulo, total, segmentos[]{rotulo, n, status}  ·  custo: ~3 linhas por segmento. Largura calculada pelo renderizador (n/total).

dados que geraram isto — copie e troque os valores

    }
  ]
}
